How it works

A simple, safe nightly pipeline

Python only moves files. All cleaning and modelling lives in SQL Server: a staging database RETAIL_STG and a data warehouse RETAIL_DWH.

File arrives

The nightly CSV lands in the inbox folder.

Load to staging

Copied unchanged into RETAIL_STG.stg.salesRaw.

Clean

The view stg.salesClean applies every cleaning rule.

Build warehouse

etl.loadWarehouse updates dimensions and fact.sales.

Archive & log

File moved to archive; run logged in etl.runLog.

Load once

Every line has a fingerprint. Data already loaded is skipped, so nothing is double-counted.

Full history

Products and customers are SCD type 2: changes become new versions, old sales keep the old version.

No hard deletes

Lines removed from a corrected invoice are soft-deleted with a timestamp, never lost.

All or nothing

Each load is one transaction. If anything fails, nothing changes and the error is logged.

Sales build strongly towards Christmas

Net sales (bars) and orders (line) by month

November 2011 peaked at £1.43m. September–November averaged 1.8× a normal month, so stock, staff and marketing should be planned from late summer. December covers only 1–9 Dec.

When customers order

Number of orders by day of week and hour

fewermore orders
No orders on Saturdays. Thursday is the busiest day, and 78% of orders arrive between 10:00 and 15:59. The peak is Wednesday at noon. Staff customer service and the warehouse around midday.

Markets outside the UK

Net sales by country

The UK brings 85% of sales. Overseas orders are bigger: £850 on average against £499 in the UK, and the Netherlands averages £3.1k per order.

Loyal customers carry the business

Share of customers vs share of sales, by segment

Champions are 26% of customers but bring 68% of sales. 656 good customers are "at risk" of leaving: a win-back offer to them is the quickest revenue opportunity.

Going live

Hands-off, every night

Start on the existing server, then move to managed cloud services as the business grows.

Option A · quick start

Existing server

SQL Server Agent runs python main.py run at 02:30. Files arrive in a shared folder, and Database Mail emails the team if a run fails. Live within days, at no extra cost.

Option B · recommended for growth

Microsoft Azure

Blob Storage receives the file, Data Factory runs the pipeline, Azure SQL hosts both databases, Key Vault keeps secrets, Monitor sends alerts, and Power BI refreshes the dashboards.
